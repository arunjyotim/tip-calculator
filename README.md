# Tip Calculator

This application calculates tips and splits bills among multiple people.

## Features

- Quick tip percentage selection buttons
- Custom tip amount entry field
- Adjustable split bill counter
- Instant calculation of per person totals

## How it works

The script listens for input changes on the bill amount, tip selection, and split count. It instantly recomputes the tip total, overall cost, and individual shares using pure JavaScript math.

## Run

Open `index.html` in a browser. No install or build step.

## Files

- `index.html`: Main markup structure with layout elements
- `style.css`: Complete styling using design tokens
- `script.js`: Calculation logic and event handling
